## 📋 The task

The teacher writes a one-paragraph spec for a **2-page React app** against a public API you have not used. It must have routing, loading/error states, and one piece of shared state. You build it live while explaining your decisions as you go.

## ✅ Passing means

- It works
- Components are split sensibly
- No state bugs — no stale values, no mutation
- Every decision is defensible

## 🤖 AI in exams

**None.** Not for explanation, not for code, not for debugging. Docs and search only, and only where the format above allows them. An exam is the one place where the point is to find out what *you* can do unaided.
