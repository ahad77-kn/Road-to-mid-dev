# Layout Decisions

## 1. Page Skeleton — Grid
Grid because the page has two dimensions: rows and columns, with the top bar, sidebar, and main area arranged in a clear page structure.

## 2. Top Bar — Flexbox
Flexbox because the logo, search box, and avatar need to be arranged in one horizontal row and spaced apart.

## 3. Video Grid — Grid
Grid because multiple video cards need to be arranged into rows and columns and automatically respond to the available width.

## 4. Video Card Internals — Flexbox
Flexbox because the avatar and video information need to be arranged in one direction inside each card.
