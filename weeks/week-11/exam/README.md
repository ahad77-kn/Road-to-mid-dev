## 📋 The task

You are given a **repo you have never seen**, containing a bug and a feature request written as an issue.

1. Clone it and get it running from the README alone
2. Reproduce the bug and locate it with DevTools
3. Fix it on a branch, with a commit message explaining *why*
4. Implement the feature on a second branch
5. Open two PRs with clear descriptions
6. Respond to the teacher's review comments

## ✅ Passing means

- Clean history — small, meaningful commits
- Both branches work
- PRs are readable and explain the change
- You can explain a codebase you met this morning

## 🤖 AI in exams

**None.** Not for explanation, not for code, not for debugging. Docs and search only, and only where the format above allows them. An exam is the one place where the point is to find out what *you* can do unaided.
