## 📋 The task

**Part A — 5 logic problems, console only:** reverse the words in a sentence keeping punctuation · find and count duplicates in an array · sum every number in a nested object at any depth · group an array of objects by a key · running balance from a transaction list.

**Part B —** the teacher writes a one-paragraph spec for a small app against an API you have never used. Build it live.

## ✅ Passing means

- All 5 Part A problems solved and explained
- Part B app works, with loading / error / empty states
- You can explain **every line** out loud

## 🤖 AI in exams

**None.** Not for explanation, not for code, not for debugging. Docs and search only, and only where the format above allows them. An exam is the one place where the point is to find out what *you* can do unaided.
