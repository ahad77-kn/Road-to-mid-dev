## ▶️ How to run it

**No HTML. No browser. No setup.** Open the terminal, go into the assignment
folder, and run the file:

```bash
cd weeks/week-04/day-5/assignment
node yourfile.js
```

`node` is already installed. The output appears in the terminal.

**Run every file after every change.** Write one line, run it, read what came
back. If it prints an error, the error tells you the file and the line number —
read it, it is not hiding anything. That write-run-read-fix loop *is*
programming; everything else is typing.

> Chrome DevTools → Console works too, and is handy for one-liners.
> For a whole file, `node` is the one to use.
