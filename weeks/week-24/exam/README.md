## 📋 The task

Present your live capstone, then defend it. Expect: *"why this schema?"* · *"what happens when the token expires?"* · *"show me the line that stops user A reading user B's data"* · *"make this button do X — live, now"* · *"something broke in production, walk me through your first five minutes"*.

## ✅ Passing means

- The app is live and works from the teacher's machine
- The demo is clear and confident
- Technical questions answered honestly — "I don't know, here's how I'd find out" is a good answer
- The live change is completed
- The code could be handed to another developer

## 🤖 AI in exams

**None.** Not for explanation, not for code, not for debugging. Docs and search only, and only where the format above allows them. An exam is the one place where the point is to find out what *you* can do unaided.
