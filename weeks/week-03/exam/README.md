## 📋 The task

The teacher gives you a **screenshot** of a real website section (a hero + card grid). Recreate it, responsive, without looking at the real site's code.

## ✅ Passing means

- Layout matches the screenshot on mobile **and** desktop
- Clean, consistent class names
- No absolute-positioning hacks, no magic numbers to force alignment
- Flexbox and Grid each used where appropriate
- You can defend every rule you wrote

## 🤖 AI in exams

**None.** Not for explanation, not for code, not for debugging. Docs and search only, and only where the format above allows them. An exam is the one place where the point is to find out what *you* can do unaided.
