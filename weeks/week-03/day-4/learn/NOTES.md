## The teacher's questions — my answers, from memory

1. Why does < section > beat < div > for a screen-reader user?
ans. section gives meaningful name to the page while div does not.section is a whole section while div is just a divider or separator.readers understand and navigate by sections easily.
2. When should alt be empty, and when is empty alt a bug?
ans. Use alt="" for decorative images that add no useful information. Empty alt is a bug when the image contains important information or communicates something to the user.
3. What is the correct heading order, and what breaks if you jump h2 → h4?
ans. the order is (h1 h2 h3 h4)while skipping order can make the screeen structure confusing.
4. What are CSS custom properties and what do they give you that a Sass variable does not?
ans. CSS custom properties are variables such as --color-dark. They can be changed at runtime in the browser, while Sass variables are replaced when Sass is compiled.
5. Prove it: turn off CSS entirely (DevTools → disable stylesheets). The page must still be readable and in a sensible order.
ans. the html should still show readable content in the correct order because semantic html provides the structure without the css.
