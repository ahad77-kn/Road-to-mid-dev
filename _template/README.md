# Templates

| File | Who uses it | When |
| --- | --- | --- |
| [`ASSESSMENT.md`](ASSESSMENT.md) | **teacher** | copy into `weeks/week-NN/day-N/ASSESSMENT.md` when marking a day |
| [`EXAM.md`](EXAM.md) | student + teacher | copy into `weeks/week-NN/exam/EXAM.md` at a phase exam |

The student does **not** need to copy anything: every day folder already ships with
`learn/NOTES.md` ready to fill in.
